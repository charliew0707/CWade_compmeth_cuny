7.) Functions: 
    code that takes in an operation or input and and return ouputs, makes code reuasabel good programming practice
    use def factorial(n):
        f = 1
        for k in range(1,n+1)
            f = f*k
        return f

    indentation matters, return ends the function/for loop, must define before use

    Return, send back info/variables from process, etc, return x,y,z (and you exit function)
    have to match data type

    Arguments: functions have arguments(argument) positional or keyword (n1,n2,n3) are positional arguments
    keyword arguments: def length(x,y,z,cm=False)
